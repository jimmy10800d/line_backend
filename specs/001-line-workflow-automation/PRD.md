## 1. 產品概述 (Product Overview)

### 1.1 產品願景 (Vision)

打造一個以 **LINE** 為操作介面的個人自動化助手，讓使用者能夠透過日常使用的通訊軟體，輕鬆執行跨平台的自動化任務，提升個人工作效率。

### 1.2 產品定位 (Positioning)

| 類似產品 | 我們的差異 |
|----------|-----------|
| n8n / Zapier | 以 LINE 對話為主要介面，不需要開啟網頁即可操作 |
| IFTTT | 整合 AI 對話理解，支援自然語言指令 |
| LINE Bot | 不只是聊天機器人，而是完整的自動化流程引擎 |

### 1.3 目標用戶 (Target User)

- **主要用戶**: 個人使用者（單一用戶系統）
- **用戶特徵**: 
  - 熟悉 LINE 操作
  - 有跨平台整合需求（Google Calendar、Notion、GitHub）
  - 希望自動化日常重複性工作
  - 願意使用 AI 服務提升效率

### 1.4 核心價值主張 (Value Proposition)

1. **便捷性**: 透過 LINE 隨時隨地執行自動化任務
2. **智能化**: AI 對話理解，用自然語言下達指令
3. **整合性**: 串接多個外部服務，打破平台隔閡
4. **自動化**: 排程執行，真正的「設定後忘記」

### 2.2 功能清單

#### P1 - 核心功能（MVP 必須）

| ID | 功能 | 描述 | 驗收標準 |
|----|------|------|----------|
| FR-001 | LINE Webhook 接收 | 接收並解析 LINE 訊息 | 系統能正確接收所有類型的 LINE 訊息 |
| FR-002 | 指令解析 | 支援 /command 格式指令 | 正確識別指令和參數 |
| FR-002a | AI 對話理解 | 整合 ChatGPT 理解自然語言 | 能將「幫我查今天的行程」轉換為 calendar 查詢 |
| FR-003 | 任務執行 | 執行預設任務並回覆結果 | 3 秒內回覆或顯示「處理中」 |
| FR-004 | 非同步執行 | 長時間任務不阻塞 | 任務在背景執行，完成後主動通知 |

#### P2 - 重要功能

| ID | 功能 | 描述 | 驗收標準 |
|----|------|------|----------|
| FR-005 | 工作流程建立 | 透過對話建立自訂流程 | 5 分鐘內完成 3 步驟流程建立 |
| FR-006 | 流程儲存 | 儲存流程定義 | 流程可正確儲存和載入 |
| FR-007 | 流程開關 | 啟用/停用流程 | 狀態切換即時生效 |
| FR-008 | 流程版本 | 版本控制 | 可查看歷史版本 |
| FR-009 | OAuth 授權 | 支援 OAuth 2.0 | 2 分鐘內完成授權 |
| FR-010 | 憑證安全儲存 | 加密儲存 Token | Token 不可被明文讀取 |
| FR-011 | 外部服務整合 | Google Calendar、Notion、GitHub | 各服務基本 CRUD 操作 |

#### P3 - 進階功能

| ID | 功能 | 描述 | 驗收標準 |
|----|------|------|----------|
| FR-012 | Cron 排程 | 支援 Cron 格式 | 正確解析 Cron 表達式 |
| FR-012a | 時區處理 | 固定台灣時區 UTC+8 | 時間顯示和執行符合 UTC+8 |
| FR-013 | 排程類型 | 一次性和重複排程 | 兩種類型都能正確執行 |
| FR-014 | 排程準確性 | 誤差 < 1 分鐘 | 99% 任務準時執行 |
| FR-015 | 執行歷史 | 記錄所有執行 | 可查詢歷史紀錄 |
| FR-015a | 資料保留 | 保留 7 天 | 超過 7 天自動清除 |
| FR-016 | 錯誤日誌 | 記錄並可查詢 | 錯誤詳情可追蹤 |
| FR-017 | 狀態通知 | 執行狀態通知 | 失敗時主動通知 |

### 2.3 MVP 預設任務清單

#### Google Calendar 整合
| 指令 | 功能 | 範例 |
|------|------|------|
| `/calendar today` | 查詢今日行程 | 顯示今天所有行程 |
| `/calendar week` | 查詢本週行程 | 顯示本週行程摘要 |
| `/calendar add` | 新增行程 | `/calendar add 明天 14:00 開會` |

#### Notion 整合
| 指令 | 功能 | 範例 |
|------|------|------|
| `/notion search` | 搜尋頁面 | `/notion search 專案計畫` |
| `/notion add` | 新增頁面 | `/notion add 會議記錄` |
| `/notion list` | 列出資料庫項目 | `/notion list 待辦事項` |

#### GitHub 整合
| 指令 | 功能 | 範例 |
|------|------|------|
| `/github issues` | 查詢 Issue | `/github issues open` |
| `/github prs` | 查詢 PR | `/github prs pending` |
| `/github create` | 建立 Issue | `/github create bug 登入失敗` |

#### 基本任務
| 指令 | 功能 | 範例 |
|------|------|------|
| `/weather` | 天氣查詢 | `/weather 台北` |
| `/remind` | 設定提醒 | `/remind 30分鐘後 喝水` |
| `/calc` | 簡單計算 | `/calc 100 * 1.05` |
| `/help` | 查看幫助 | 顯示所有可用指令 |

## 3. 非功能需求 (Non-Functional Requirements)

### 3.1 效能需求

| 項目 | 目標 |
|------|------|
| 回應時間（簡單任務） | < 3 秒 |
| 回應時間（複雜任務） | 立即回覆「處理中」 |
| 並發用戶數 | 100 用戶同時執行 |
| 排程準確率 | 99%（誤差 < 1 分鐘） |

### 3.2 可用性需求

| 項目 | 目標 |
|------|------|
| 系統可用性 | 99.5% uptime |
| 資料備份 | 每日自動備份 |
| 故障恢復 | < 30 分鐘 |

### 3.3 安全性需求

| 項目 | 要求 |
|------|------|
| OAuth Token 儲存 | 加密儲存 |
| API 通訊 | HTTPS only |
| 敏感資料 | 不記錄在日誌中 |
| LINE 驗證 | 驗證 Webhook 簽名 |

### 3.4 限制條件

| 項目 | 限制 |
|------|------|
| 使用者類型 | 單一用戶（個人使用） |
| 網頁介面 | 簡單管理介面（非拖拉式） |
| 時區 | 固定台灣時區 UTC+8 |
| 資料保留 | 7 天 |
